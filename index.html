Now In Code curates standout UI and motion design and turns it into production-ready components you can drop into your React Native and web apps.

Launching soon

What it will do

  • A curated design feed. Hand-picked interface and motion work, credited to its creators and linked to the original posts.
  • A component library. Onboarding flows, controls, transitions, shader backgrounds and more, built with Expo, Reanimated and Skia, each with a live preview and documented parameters.
  • Delivery for people and coding agents. Copy from the site, install with a CLI, or let your AI coding tool pull components directly.

How we use Google services

Now In Code uses the Google Ads API (Keyword Planner) internally, through an app called Now In Code Keywords, to research which interface patterns developers search for. That research decides which components we build first.

The app is used only by the site operator, against our own Google Ads account. It reads keyword statistics; it does not access, collect or store data from visitors' Google accounts. Details are in our privacy policy.
