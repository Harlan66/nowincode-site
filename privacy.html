Now In Code Keywords Privacy Policy

Effective 24 November 2026

This policy explains what data Now In Code ("we") handles on nowincode.com and through our internal tool, Now In Code Keywords. Contact: hello@nowincode.com.

Visitors to this website

The site currently has no user accounts, sign-in, forms, advertising or analytics, and sets no cookies. We do not collect personal information from visitors.

The site is hosted on GitHub Pages. Like any web host, GitHub may log technical data such as IP addresses to operate and secure the service; see GitHub's privacy statement. We do not receive or use those logs.

Now In Code Keywords and Google user data

Now In Code Keywords is an internal tool used only by the operator of Now In Code. It is not offered to the public, and no visitor is ever asked to sign in with Google.

  • Data sent to Google. The tool sends seed keywords and the company-owned Google Ads account ID to Google Ads Keyword Planner with the operator's authorization under the https://www.googleapis.com/auth/adwords scope. Website visitors do not authorize the app or provide Google account data.
  • Data received from Google. Google returns keyword suggestions, aggregate historical search volumes and keyword forecasts. The tool uses these results to prioritize interface patterns and components and decide how to describe them. It makes read-only requests and does not manage ad campaigns.
  • Storage and retention. We store the OAuth refresh token in a local configuration file on the operator's computer. The operator may retain selected aggregate keyword statistics in internal research notes for component planning.
  • Sharing. Google processes requests to provide the Keyword Planner service. We do not sell Google user data, disclose it to other third parties, use it for advertising, or use it to train or improve AI or machine-learning models.
  • Limited Use. Now In Code's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access and deleting data. The operator can revoke the app's access at myaccount.google.com/permissions and delete the stored token from the local configuration file. For questions about retention or requests to remove retained data, email hello@nowincode.com.

Future changes

When we launch accounts, payments or analytics, we will update this policy before those features go live and change the effective date above.

Contact

For questions or requests about your data, email hello@nowincode.com.
